# Flechazo

Puzle de flechas: toca las flechas en el orden correcto para vaciar el tablero y completar murales.
El juego está en `www/index.html` (un solo archivo con todas las imágenes dentro).

Cada vez que se sube un cambio a `main`, GitHub compila la APK de Android automáticamente:
pestaña **Releases** → descarga `Flechazo.apk` en el móvil e instálala.
